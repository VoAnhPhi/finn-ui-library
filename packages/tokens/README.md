# @finn-ui/tokens

Design token foundation for Finn UI.

## Status

This package is private and pre-release. The API may change while the MVP is
being stabilized.

## Usage

```ts
import { tokens } from "@finn-ui/tokens";

const cardPadding = tokens.spacing.lg;
```

The token set includes colors, spacing, radius, typography, shadow, border
width, opacity, z-index, duration, and easing values.

## Build

```powershell
pnpm --filter @finn-ui/tokens build
```
